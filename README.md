# Aristide Izabkora — Portfolio

A responsive personal portfolio showcasing my software development work, background, and current focus.

## Projects featured

- **Community Store** — an Android marketplace project for a student community, currently in development.
- **Meet & Mani** — a beauty service marketplace project in early development.
- **SSG Auto Glass** — a service website that helps customers request a quote or call the business.

## Built with

- HTML5
- CSS3

The site is a static website. It does not need a build step or backend.

## Run locally

Download or clone this repository, then open `index.html` in a browser. Keep `style.css` in the same folder as `index.html`.

## Files

```text
index.html  Page content and structure
style.css   Layout, typography, colors, and responsive styles
README.md   Project information
```
